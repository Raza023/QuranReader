# Quran Majeed – Interactive Quran Web App

![Quran Majeed Logo](src/favicon.png)

**Quran Majeed** is a feature-rich, interactive web application for reading, listening, and studying the Holy Quran. It supports multiple translations, audio recitations, word-by-word analysis, and a user-friendly interface for both desktop and mobile devices.

---

## 🌟 Features

### 1. **Quran Reading & Navigation**
- **Surah & Juzz View**: Browse the Quran by Surah or Juzz.
- **Pagination**: Navigate through verses with pagination controls.
- **Search**: Quickly find any Surah or Juzz using the search bar.

### 2. **Audio Playback**
- **Arabic Recitation**: Listen to high-quality recitations of each verse.
- **Urdu Translation Audio**: Audio for Urdu translations.
- **Repeat Mode**: Repeat verses or Surahs for memorization.
- **Background Playback**: Continue listening even when the app is in the background.

### 3. **Translations & Word-by-Word Analysis**
- **Urdu Translation**: Read Urdu translations for each verse.
- **Word-by-Word (WBW)**: Breakdown of each Arabic word with Urdu or English meanings.
- **English Support**: Toggle between Urdu and English translations.

### 4. **User Experience**
- **Dark/Light Mode**: Switch between themes for comfortable reading.
- **Font Size Adjustment**: Increase or decrease text size.
- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop.

### 5. **Sharing & Offline Support**
- **Share Verses**: Share verses with Arabic text, translations, and word-by-word analysis.
- **Offline Resume**: Automatically resumes playback when the connection is restored.

---

## 📱 Installation & Usage

### **Online Usage**
1. Open the app in any modern web browser.
2. Use the dropdown menus to select a Surah or Juzz.
3. Navigate through verses using the pagination controls.
4. Use the audio player to listen to recitations or translations.

### **Local Setup**
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/quran-majeed.git
   ```
2. Open `index.html` in your browser.

## 🛠️ Technical Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Fonts**: Indopak Nastaleeq (Arabic), Noto Nastaliq Urdu
- **Audio**: MP3 files for recitations and translations
- **Data**: JSON files for Quran text, translations, and metadata
